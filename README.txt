# GitHub User Finder

Графический поиск пользователей GitHub с сохранением избранных.

## Автор

[Юлия Петрова]

## Описание

Приложение позволяет:
* Искать пользователей GitHub по имени.
* Просматривать основную информацию о пользователях.
* Добавлять пользователей в избранное (двойной клик по результату или вручную).
* Удалять пользователей из избранного.
* Сохранять список избранных пользователей в JSON‑файл.
